# Devansh Academy

A responsive coaching academy website built using HTML, CSS and JavaScript.

## 🌐 Live Demo

https://dev200432.github.io/devansh-academy/

## 📌 About the Project

Devansh Academy is a responsive coaching website designed to provide students with information about courses, learning programs and enquiry options.

The project focuses on clean UI, responsive design and basic JavaScript functionality.

## ✨ Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section with call-to-action buttons
- Student progress dashboard
- Course cards with course details
- Interactive course details modal
- Why Us section
- Student enquiry form
- Form validation using JavaScript
- Active navigation highlighting
- Responsive design for mobile and tablet devices
- Smooth scrolling and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
